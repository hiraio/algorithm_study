# BOJ 17071 — 숨바꼭질 5 (레벨 BFS + 홀짝)

**날짜**: 2026-04-03~04  
**유형**: 레벨 BFS + 홀짝

## 핵심 테크닉
- `visited[위치][홀짝]`, `sz = q.size()`로 시각 추적. 도달 시각 홀짝 같으면 왕복으로 대기 가능

## 잘한 부분
- BFS로 visited 완성 → 별도 for문에서 동생 위치 계산하며 비교하는 2단계 분리 구조를 스스로 이해
- 동생 위치 누적 합 계산도 정확히 구현

## 막혔던 포인트
- 1차원 visited로 홀짝 비교만 추가하면 될 줄 알았으나, 최단 시각의 홀짝이 안 맞을 때 반대 홀짝 경로를 놓침
- visited 인덱스에 위치 홀짝(N%2)을 쓰는 실수 → 시각 홀짝(t%2)이어야 함
- 레벨 단위 BFS (sz = q.size()) 패턴을 처음 접함
- q.push 누락, 범위 체크 순서, BFS 안에서 동생 위치 갱신 시도, for문 누락

## 배운 점
1. **visited 배열 차원 확장**: "탐색 결과를 담는 그릇" → 홀짝·방향·열쇠 등 상태를 차원으로 추가해 2차원, 3차원으로 확장 가능
2. **홀짝 대기 논리**: 도달 시각 ≤ t 이고 홀짝 동일 → 제자리 왕복(+1, -1)으로 시간 맞출 수 있음
3. **레벨 단위 BFS**: `sz = q.size()`로 현재 레벨 노드 수를 고정하고, 그만큼만 처리 후 t++ → 시각 추적 가능

## 복습 (2026-05-16~17)
- visited[홀짝][위치] 2단계 분리 구조(BFS 완성 → 별도 for문 체크) 다시 구현
- 막혔던 포인트 재발: visited 저장 방향 뒤집힘(flag vs 1-flag), `==` 대신 `=` 실수
- t++ 누락으로 무한루프, 동생 위치 누적 계산 오류 수정
