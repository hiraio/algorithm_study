# BOJ 1189 — 컴백홈 (DFS 백트래킹, 경로 수 세기)

**날짜**: 2026-04-08  
**유형**: DFS 백트래킹

## 잘한 부분
- 14620에서 익힌 백트래킹 패턴을 빠르게 적용
- 4방향 탐색 + visited 마킹/복원, 거리 매개변수 누적, `(0, C-1)` 도착 시 거리 K 일치 여부 체크까지 직접 작성
- 한 함수 안에 모두 넣되, 분리할지 여부도 스스로 판단 ("이건 굳이 안 나눠도 되겠다")

## 막혔던 포인트
- 베이스 케이스에서 `dist == K`만 체크하고 `return`을 안 해서 도착 후에도 for문이 실행됨
- 함수 진입 시 `visited[y][x] = 1`을 한 줄 더 써놓고는 unset은 caller가 하는 비대칭 패턴

## 배운 점
1. **visited 마킹의 두 가지 idiom**:
   - (A) caller가 자식 마킹: 진입 전 `visited[ny][nx]=1` → 재귀 → `visited[ny][nx]=0`, 시작점은 main에서 마킹
   - (B) callee가 자기 마킹: 함수 첫 줄에서 `visited[y][x]=1` → 재귀 호출 → 함수 끝에서 `visited[y][x]=0`
   - 두 패턴은 섞으면 안 됨
2. **함수 분리 여부 판단 기준**: 14620은 복잡한 변경이라 분리가 효과적이었지만, 1189는 한 칸만 건드리고 검사도 조건 3개라 굳이 분리 필요 없음. "이름을 붙이면 가독성이 올라가는가"가 기준
3. 같은 백트래킹 뼈대(상태 변경 → 재귀 → 복원)가 반복되며 점점 손에 익는 중

## 느낀 점
- 14620에서 함수 분리를 고생해서 익힌 덕에 1189는 "이건 분리 안 해도 된다"는 판단까지 빠르게 도달
