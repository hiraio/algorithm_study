# BOJ 2529 — 부등호 (DFS 백트래킹)

**날짜**: 2026-04-06  
**유형**: DFS 백트래킹

## 잘한 부분
- 첫 숫자는 부등호 비교 없이 0~9 모두 가능하므로 main에서 각각 DFS 호출하는 구조를 직접 설계
- DFS 내에서 for(0~9) 탐색하며 부등호 조건 체크, used 배열로 중복 방지, idx로 부등호 인덱스 추적

## 막혔던 포인트
- `s + num`으로 int를 바로 문자열에 추가 → `s += ('0' + num)`으로 char 변환 필요
- 문자열 `s`에 대한 백트래킹(pop_back) 누락 — used만 되돌리고 s는 안 되돌림
- `int(s)`로 비교 시도 → 10자리 넘어 int 오버플로, string 비교로 해결
- `''` (char) vs `""` (string) 혼동

## 배운 점
1. **백트래킹 되돌리기는 반드시 쌍으로**: `used[i]++` ↔ `used[i]--`, `s += ...` ↔ `s.pop_back()`. 변경한 상태는 전부 되돌려야 함
2. **idx와 depth가 같은 값으로 움직이면 하나로 합칠 수 있음** — 변수 줄이기
3. **자릿수가 같은 숫자는 string 사전순 비교 = 숫자 크기 비교** → int 오버플로 걱정 없이 max/min 비교 가능
