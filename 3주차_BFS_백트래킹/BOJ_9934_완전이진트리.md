# BOJ 9934 — 완전 이진 트리 (분할정복 + 중위순회)

**날짜**: 2026-04-07  
**유형**: 분할정복 + 중위순회

## 잘한 부분
- 중위순회의 정의로부터 "가운데가 루트"라는 핵심 통찰을 스스로 잡음
- 재귀 구조(depth 줄이며 절반씩 쪼개기)와 기저 사례(`depth==0`) 설계 직접 함
- 두 번째 시도에서 left/right 매개변수 도입 → `mid = (l+r)/2`로 루트 잡고 재귀 호출하는 구조 완성

## 막혔던 포인트
- 첫 시도에서 `go(depth, num)`으로 크기만 넘김 — 같은 크기의 왼쪽/오른쪽 서브트리를 구분할 방법이 없다는 걸 못 깨달음. "구간의 위치" 정보가 빠진 것
- `left`, `right`가 `<bits/stdc++.h>` + `using namespace std;`와 충돌(스트림 조작자)
- `int idx = ...`, `int mid = ...` 타입 선언 누락
- 결과 출력 단계 빼먹음

## 배운 점
1. **분할정복 재귀의 매개변수는 "이 함수가 보고 있는 구간이 어디인지"를 충분히 표현해야 함**. 크기만으로는 부족하고 (시작, 끝) 또는 (시작, 길이)가 필요. → 함수의 의미를 한 문장으로 정의하는 습관 필요
2. **레벨별 벡터** (`vector<int> level[20]`)에 바로 push하면 재귀 호출 순서(왼→오) 덕에 자연스럽게 좌→우 순서 보장
3. **재귀 호출 순서가 곧 트리 순회 순서** — `level[idx].push_back()` → 왼쪽 재귀 → 오른쪽 재귀 순으로 쓰면 같은 레벨 안에서 좌→우가 자동 보장

## 느낀 점
- BFS/DFS는 "틀"이 있지만 분할정복 재귀는 매번 "이 함수의 의미가 뭔지" 새로 정의해야 해서 더 어렵게 느껴짐
