# BOJ 3197 — 백조의 호수 (레벨별 BFS x 2)

**날짜**: 2026-04-05  
**유형**: 레벨별 BFS x 2

## 핵심 테크닉
- **큐 4개**: 물(waterQ/water_tempQ) + 백조(swanQ/swan_tempQ). 각각 tempQ에 막힌 셀 모아두고 턴마다 교체. visited는 누적

## 잘한 부분
- 브루트포스(매턴 DFS+BFS) 버전을 먼저 직접 설계
- 레벨별 BFS로 최적화하는 구조(큐 4개)를 강의 보고 구현

## 막혔던 포인트
- 브루트포스 버전에서 for문이 녹인 X를 다시 bfs → 연쇄 녹음 (visited 체크 누락)
- `visited_swan[swanY][swanX] = 1` 대입 대신 읽기만 해서 시작점으로 되돌아와 자기 자신을 발견
- `b2x = v[1].second` 오타 반복
- 'L' 칸도 물로 취급해야 인접 얼음이 녹는다는 점

## 배운 점
1. **레벨별 BFS를 여러 대상에 동시 적용**: 물 녹이기와 백조 이동을 각각 큐 2개씩, 총 4개 큐로 관리
2. **tempQ 패턴**: 현재 턴에서 막힌 셀(X)을 tempQ에 모아두고, 다음 턴에 메인 큐로 교체. visited는 초기화하지 않고 누적
3. **브루트포스 먼저 → 최적화 순서가 효과적**: 브루트포스에서 "매턴 전체 탐색"의 비효율을 체감한 후 레벨별 BFS의 필요성을 이해
