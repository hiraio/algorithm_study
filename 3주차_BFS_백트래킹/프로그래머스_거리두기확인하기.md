# 프로그래머스 — 거리두기 확인하기 (Lv.2, 격자 BFS)

**날짜**: 2026-05-16~17 (소프티어 대비)  
**유형**: 격자 BFS 조건 분기

## 풀이
- BFS로 각 P에서 거리 2 이내 다른 P 체크하는 구조

## 막혔던 포인트
- answer를 사람 단위로 push (대기실 단위여야 함)
- 0/1 뒤집힘
- 범위 체크 >5 → >=5
- visited==0(미방문)을 위반으로 오판 (0-1=-1 <= 2)

## 다른 풀이 분석
- **is_in_use 도장 패턴**: P가 옆 O에 표시, 다른 P가 같은 O에 또 표시하려 하면 P-O-P 위반. BFS 없이 O(25)
