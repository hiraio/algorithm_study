# BOJ 1987 — 알파벳 (DFS 백트래킹)

**날짜**: 2026-04-06  
**유형**: DFS 백트래킹

## 핵심 테크닉
- 알파벳 사용 배열로 visited 대체. 상태 변경→재귀→상태 복원. 모든 경로 탐색하며 최대 깊이 갱신

## 잘한 부분
- DFS 백트래킹 구조(상태 변경 → 재귀 → 상태 복원)를 직접 구현
- 알파벳 배열로 visited 역할을 대체하는 아이디어도 이해

## 막혔던 포인트
- BFS로 접근하려 했으나, 경로마다 사용한 알파벳 상태가 달라 BFS로는 상태 관리가 어려움을 깨달음
- 기저 사례(return 조건)를 명시적으로 써야 한다고 생각했으나, 갈 곳이 없으면 for문이 실행 안 되어 자연스럽게 종료됨을 이해

## 배운 점
1. **BFS vs DFS 판단 기준**: 최단 거리면 BFS, 모든 경로 탐색 / 최대 경로면 DFS 백트래킹
2. **백트래킹의 핵심은 "되돌리기"**: `alpha[...]++` → 재귀 → `alpha[...]--`로 다른 경로 탐색 시 깨끗한 상태 보장
3. **알파벳 사용 여부 추적이 곧 visited 역할** → 별도 visited 배열 불필요
