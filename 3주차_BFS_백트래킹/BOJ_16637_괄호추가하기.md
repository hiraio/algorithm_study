# BOJ 16637 — 괄호 추가하기 (재귀 브루트포스)

**날짜**: 2026-04-02  
**유형**: 재귀 브루트포스

## 핵심 테크닉
- 각 위치에서 "괄호 안 씀 / 씀" 두 선택지 → 재귀로 전부 시도

## 잘한 부분
- 숫자/연산자 분리, calc·solve 구조를 직접 설계

## 막혔던 포인트
- calc 반환형 void로 선언
- ret/cnt 변수를 덮어써서 두 분기가 간섭
- 종료 조건에서 null 비교

## 배운 점
- "각 위치에서 선택지 전부 시도 → 다음으로 넘기기" 재귀 브루트포스 패턴
- solve 호출 시 값을 직접 넘겨야 분기가 독립적
