# BOJ 13913 — 숨바꼭질 4 (BFS + 경로 역추적)

**날짜**: 2026-04-02  
**유형**: BFS + 경로 역추적

## 핵심 테크닉
- `parent[]` 배열로 "어디서 왔는지" 기록 → 재귀로 역추적

## 잘한 부분
- BFS 최단거리 로직을 먼저 단계적으로 구현하고, parent 배열 + 재귀 역추적을 직접 설계

## 막혔던 포인트
- `2*N`(시작점)을 `2*n`(현재 위치)으로 써야 하는 대소문자 실수
- 종료 조건에서 `visited[mN] == K`(거리값과 좌표 비교)로 잘못 작성
- 역추적 방법 자체를 떠올리기 어려움 — 경로가 여러 개인데 하나만 저장해도 되는지 고민

## 배운 점
- parent 배열로 "어디서 왔는지"만 기록하면 역추적 가능
- 모든 최단 경로를 구해야 하면 parent를 벡터로 바꾸고 재귀 백트래킹으로 조합 탐색
- 재귀 브루트포스 패턴이 BFS 역추적, 백트래킹 등 여러 곳에서 반복적으로 등장

## 코드 리팩토링 (강의 참고)
- `here` 변수 + `prev[]` 배열 + `for(int next : {here+1, here-1, 2*here})` 패턴으로 정리
- 역추적은 `for(int i = K; i != N; i = prev[i])` 반복문 + reverse

## 복습 (2026-05-16~17)
- parent 배열 역추적 패턴 복기
- `prev` 이름 충돌(std::prev) 경험
- reverse(v.begin(), v.end()) 패턴 재확인
