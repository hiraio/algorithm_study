# BOJ 1525 — 퍼즐 (상태공간 BFS + map)

**날짜**: 2026-04-13  
**유형**: 상태공간 BFS + map

## 잘한 부분
- map과 string 상태 표현을 처음 배운 후 1시간 내에 BFS 구조 완성
- 2D↔1D 변환(pos/3, pos%3)을 자연스럽게 적용
- swap→탐색→swap 복원 백트래킹 패턴을 BFS 안에서 정확히 구현
- visited 거리 누적, 도달 불가 -1 처리까지 직접 설계

## 막혔던 포인트
- 처음에 전역 2D 배열로 접근 → BFS는 여러 상태가 큐에 동시에 존재하므로 전역 배열 하나로는 상태 관리 불가능
- 목표 문자열 "1234567890"(10글자)으로 오타 → "123456780"(9글자)이어야 함
- swap 복원을 continue 경로에서만 했다가 push 후에도 필요하다는 것 인지

## 배운 점
1. **상태가 크면 map<string, int>으로 visited 대체**: 배열 인덱스로 표현 불가능한 상태(퍼즐 배치 등)는 문자열로 직렬화해서 map의 키로 사용
2. **BFS에서 전역 상태 사용 불가**: 큐에 여러 상태가 쌓이므로, 각 상태를 독립적으로 들고 다녀야 함 (string을 큐에 넣기)
3. 3주차에서 배운 패턴들(2D↔1D 변환, swap 복원, BFS visited 누적)이 새로운 유형에서도 그대로 적용됨을 확인
