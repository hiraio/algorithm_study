# BOJ 14497 — 주난의 난 (레벨별 BFS, 비균일 비용)

**날짜**: 2026-04-05  
**유형**: 레벨별 BFS (비균일 비용)

## 핵심 테크닉
- **큐 2개 + while 2중**: `'0'`→현재 큐, `'1'`→next_q. `sz` 방식 불가 (현재 큐에 동적 추가되므로)

## 잘한 부분
- 큐에서 pair 꺼내는 tie 문법, 기본 BFS 구조를 직접 작성

## 막혔던 포인트
- `q = next_q`를 안쪽 while 안에 넣어 매 원소마다 큐 교체됨
- `visited`를 범위 체크 전에 설정 → 배열 밖 접근
- `'1'` 칸에 visited 안 해서 중복 삽입
- `tie(x,y)` 순서가 `{행,열}`과 불일치
- 후위감소(`junanY--`) 사용으로 배열 표시 위치와 변수 값 불일치
- 범위 체크 `> N` → `>= N`

## 배운 점
1. **레벨별 BFS**: 비용이 0과 1로 나뉠 때, `'0'`은 현재 큐에 `'1'`은 next_q에 넣고 2중 while로 라운드를 분리
2. **`sz = q.size()` 패턴의 한계**: 한 레벨 안에서 큐 크기가 고정일 때만 사용 가능. 현재 큐에 동적으로 추가되면 큐 2개로 분리해야 함
3. **0-1 BFS(deque) 개념**: `'0'`이면 앞에, `'1'`이면 뒤에 넣는 방식. 나중에 배울 것
