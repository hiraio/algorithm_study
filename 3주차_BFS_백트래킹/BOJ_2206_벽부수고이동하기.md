# BOJ 2206 — 벽 부수고 이동하기 (BFS 상태확장)

**날짜**: 2026-04-13  
**유형**: BFS 상태확장

## 잘한 부분
- 17071에서 배운 visited 차원 확장을 스스로 적용
- `visited[2][N][N]`으로 "벽 부쉈냐/안 부쉈냐" 상태 분리하는 구조를 직접 설계
- 큐에 `{cnt, y, x}` 튜플로 상태를 넘기는 것도 직접 구현

## 막혔던 포인트
- 튜플 push 순서 `{y,x,cnt}`와 tie 순서 `{cnt,y,x}` 불일치
- `==` 대신 `=` 대입 실수 (15684에 이어 반복)
- `visited[cnt][ny][nx] + 1` — 현재 위치가 아닌 다음 위치에서 거리를 읽음
- 출력 로직에서 -1 조건을 "둘 다 0"이 아닌 "하나만 0"으로 잘못 작성
- if/else if 연결 없이 독립 if문 3개로 다중 출력

## 배운 점
1. **visited 차원 확장 패턴**: 같은 좌표라도 "상태가 다르면 다른 노드"로 취급. `visited[상태][y][x]`로 분리
2. **조건 분기 깔끔하게**: `if(벽 && 이미 부쉈으면) continue; int ncnt = cnt; if(벽) ncnt = 1;`으로 하면 cnt==0/1 분기를 따로 안 나눠도 됨
3. **차원 확장은 추가 상태 가짓수가 작을 때 유효** (2, K+1, 64 등). 상태가 너무 크면 map으로 전환 (→ BOJ 1525)

## 재풀이 (2026-06-04)
코드 안 보고 재구현. (4/13 이후 4/24·4/25·6/2·6/3 네 번 미뤄온 복습을 드디어 청산)

### 잘한 부분
- **6/2에 막혔던 바로 그 지점을 넘음**: 큐에 `(w, y, x)` 상태를 직접 담아 상태공간 BFS 완성. 본인 반복 약점이던 "큐에 상태 안 담는 구조 결함" 극복
- 분기를 `int nextw = w; if(board[ny][nx]==1) nextw=1;`로 깔끔하게 처리 (위 "배운 점 2" 스스로 재현)
- 방문 체크 `if(visited[nextw][ny][nx]) continue;`, 시작값 `visited[0][0][0]=1`, 미도달 시 -1 출력까지 정확히 작성

### 막혔던 포인트
- **입력 파싱**: 격자가 `0100`처럼 숫자가 공백 없이 붙어 나오는데 `cin >> int`로 읽어 한 줄이 정수 하나로 빨려 들어감 → 정답 9(오답). `string s; cin >> s; board[i][j] = s[j]-'0';`로 수정
- 처음엔 벽 부술 때 거리 레이어 인덱스를 `visited[w][..] = visited[w+1][..]+1`로 거꾸로 적었음 (직전 풀이 막힘과 동일 계열) → `visited[nextw][..] = visited[w][..]+1`로 통일하며 해결

### 배운 점
- **"붙어 나오는 격자 입력은 string으로 한 줄씩 받아 `s[j]-'0'`로 분해"** — idiom으로 고정
- BFS는 거리순으로 큐를 처리하므로 **도착 칸을 처음 pop하는 순간이 곧 최소**. 그때 break면 됨
