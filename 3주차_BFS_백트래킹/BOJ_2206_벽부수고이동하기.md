# BOJ 2206 — 벽 부수고 이동하기 (BFS 상태확장)

**날짜**: 2026-04-13  
**유형**: BFS 상태확장

## 잘한 부분
- 17071에서 배운 visited 차원 확장을 스스로 적용
- `visited[2][N][N]`으로 "벽 부쉈냐/안 부쉈냐" 상태 분리하는 구조를 직접 설계
- 큐에 `{cnt, y, x}` 튜플로 상태를 넘기는 것도 직접 구현

## 막혔던 포인트
- 튜플 push 순서 `{y,x,cnt}`와 tie 순서 `{cnt,y,x}` 불일치
- `==` 대신 `=` 대입 실수 (15684에 이어 반복)
- `visited[cnt][ny][nx] + 1` — 현재 위치가 아닌 다음 위치에서 거리를 읽음
- 출력 로직에서 -1 조건을 "둘 다 0"이 아닌 "하나만 0"으로 잘못 작성
- if/else if 연결 없이 독립 if문 3개로 다중 출력

## 배운 점
1. **visited 차원 확장 패턴**: 같은 좌표라도 "상태가 다르면 다른 노드"로 취급. `visited[상태][y][x]`로 분리
2. **조건 분기 깔끔하게**: `if(벽 && 이미 부쉈으면) continue; int ncnt = cnt; if(벽) ncnt = 1;`으로 하면 cnt==0/1 분기를 따로 안 나눠도 됨
3. **차원 확장은 추가 상태 가짓수가 작을 때 유효** (2, K+1, 64 등). 상태가 너무 크면 map으로 전환 (→ BOJ 1525)
