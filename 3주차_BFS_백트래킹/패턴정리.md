# 3주차 패턴 정리

## BFS 문제별 핵심 테크닉

| 문제 | 유형 | 핵심 테크닉 |
|------|------|------------|
| BOJ 4179 (불!) | 멀티소스 BFS | 불과 사람 BFS 따로 돌리고, 사람 이동 시 불 도착 시간과 비교 |
| BOJ 12851 (숨바꼭질 2) | BFS + 경로 수 | `ways[]` 배열로 최단 경로 가짓수 누적. 같은 레벨 재방문 시 ways만 더함 |
| BOJ 13913 (숨바꼭질 4) | BFS + 경로 역추적 | `parent[]` 배열로 "어디서 왔는지" 기록 → 재귀로 역추적 |
| BOJ 16637 (괄호 추가하기) | 재귀 브루트포스 | 각 위치에서 "괄호 안 씀 / 씀" 두 선택지 → 재귀로 전부 시도 |
| BOJ 17071 (숨바꼭질 5) | 레벨 BFS + 홀짝 | `visited[위치][홀짝]`, `sz = q.size()`로 시각 추적 |
| BOJ 14497 (주난의 난) | 레벨 BFS (비균일 비용) | 큐 2개 + while 2중: `'0'`→현재 큐, `'1'`→next_q |
| BOJ 3197 (백조의 호수) | 레벨 BFS x 2 | 큐 4개: 물 + 백조 각각 tempQ 패턴 |
| BOJ 1525 (퍼즐) | 상태공간 BFS + map | map<string, int>으로 visited 대체, string을 큐에 넣기 |
| BOJ 2206 (벽 부수고 이동) | BFS 상태확장 | `visited[상태][y][x]` 차원 확장 |
| BOJ 1987 (알파벳) | DFS 백트래킹 | 알파벳 배열로 visited 대체, 상태 변경→재귀→복원 |
| BOJ 2529 (부등호) | DFS 백트래킹 | used 배열 + string pop_back 백트래킹 |

| BOJ 15686 (치킨 배달) | 백트래킹 + 시뮬레이션 | 조합 생성 + 즉시 평가 |

## 레벨별 BFS 패턴 비교

```
패턴 1: sz 고정 (큐 크기 안 변할 때 — BOJ 17071)
while(!q.empty()) {
    int sz = q.size();
    for(int i = 0; i < sz; i++) { ... }
    level++;
}

패턴 2: 큐 2개 (현재 레벨에서 큐가 늘어날 때 — BOJ 14497)
while(!q.empty()) {
    queue next_q;
    jump++;
    while(!q.empty()) {
        // '0' → q에 push (계속 퍼짐)
        // '1' → next_q에 push (다음 라운드)
    }
    q = next_q;
}

패턴 3: tempQ 교체 (큐를 턴 간 유지 — BOJ 3197)
while(true) {
    while(!q.empty()) {
        // 통과 가능 → q에 push
        // 막힘(X) → tempQ에 push
    }
    q = tempQ; clear(tempQ);
    // visited는 초기화 안 함 (누적)
}

패턴 4: 0-1 BFS (deque — 나중에 배울 것)
// '0' → deque 앞에, '1' → deque 뒤에
```

## 반복 실수 패턴
1. **배열 인덱스 순서 불일치** (14620, 15684): `board[행][열]` vs `board[열][행]` → 선언 옆에 의미 메모 강제
2. **for 루프 변수 vs 파라미터 혼동** (14620, 15684, 15686): `start/i`, `idx/i` 계열 → 루프 안에서는 반드시 루프 변수 사용
3. **`==` 대신 `=` 실수** (15684, 2206): 조건문에서 대입 연산자 사용
