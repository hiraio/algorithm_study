# BOJ 15686 — 치킨 배달 (백트래킹 + 시뮬레이션)

**날짜**: 2026-04-13  
**유형**: 백트래킹 + 시뮬레이션

## 잘한 부분
- 치킨집 조합 → 거리 계산 → 최솟값 갱신 구조를 직접 설계
- combi 기저 조건에서 바로 거리 계산하는 깔끔한 구조로 스스로 전환
- push_back/pop_back 백트래킹 패턴 자연스럽게 적용

## 막혔던 포인트
- cList를 지역변수로 선언해서 재귀 간 공유 안 됨
- `for`와 `if` 혼동 (기저 조건)
- 루프 변수 `i` 대신 `start + 1` 넘기는 실수 (14620, 15684에 이어 세 번째)
- 꺾쇠 `>>>` 개수 부족
- `.first()` 함수 호출로 작성 (멤버 변수인데)

## 배운 점
1. **조합 생성 + 즉시 평가**: chickenList에 저장 후 순회보다, combi 기저에서 바로 계산이 깔끔. 14620에서 배운 "백트래킹 안에서 바로 처리" 패턴 재확인
2. **전역 벡터 + push/pop = 백트래킹 상태 관리**: visited 배열의 마킹/복원과 동일한 원리가 벡터에서도 적용됨
