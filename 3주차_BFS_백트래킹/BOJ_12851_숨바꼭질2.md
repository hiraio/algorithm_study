# BOJ 12851 — 숨바꼭질 2 (BFS + 경로 수 세기)

**날짜**: 2026-04-02  
**유형**: BFS + 경로 수

## 핵심 테크닉
- `ways[]` 배열로 최단 경로 가짓수 누적. 같은 레벨 재방문 시 ways만 더함

## 잘한 부분
- BFS 기본 구조, 3방향 탐색을 dy/dx 스타일로 처리, 같은 레벨 재방문 조건 이해

## 막혔던 포인트
- ret++로 경우의 수를 세려 함 → BFS에서 노드는 한 번만 큐에 들어가므로 경로 수 누락

## 배운 점
- 최단 경로 가짓수는 ways 배열로 별도 추적 (`ways[next] += ways[cur]`)
- 처음 방문 → 큐 push + ways 설정 / 같은 레벨 재방문 → ways만 누적
