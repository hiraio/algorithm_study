# BOJ 1062 — 가르침 (DFS 백트래킹 + 비트마스킹)

**날짜**: 2026-05-29
**유형**: DFS 백트래킹(배운다/안 배운다 분기) + 비트마스킹(학습 글자 집합 / 단어 글자 집합)

## 핵심 테크닉
- 알파벳 26개를 **"배우는 경우 / 안 배우는 경우" 두 갈래로 분기**하는 DFS 백트래킹을 처음 접함
- 학습한 글자 집합과 각 단어의 글자 집합을 모두 **비트마스크 정수**로 표현 → `(word & mask) == word`로 "이 단어를 읽을 수 있는가"를 O(1) 판정
- `anta_` 4글자 + `_tica` → 모든 단어가 `a, n, t, i, c`를 반드시 포함하므로 이 5글자는 **무조건 배운 것으로 고정**, 분기 대상에서 제외

## 코드 (강의 보고 작성)
```cpp
#include<bits/stdc++.h>
using namespace std;

const int max_n = 50;
int n, k, words[max_n];
string str;

int count(int mask){
    int cnt = 0;
    for(int word : words)
        if(word && (word & mask) == word) cnt++;
    return cnt;
}

int go(int index, int k, int mask){
    if(k < 0) return 0;
    if(index == 26) return count(mask);      // z까지 다 봤으면 정답 집계
    int ret = go(index + 1, k - 1, mask | (1 << index));  // 배우는 경우
    if(index != 'a'-'a' && index != 'n'-'a' && index != 't'-'a'
       && index != 'i'-'a' && index != 'c'-'a')           // antic은 강제 학습
        ret = max(ret, go(index + 1, k, mask));            // 안 배우는 경우
    return ret;
}

int main(){
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);
    cin >> n >> k;
    for(int i = 0; i < n; i++){
        cin >> str;
        for(int j = 0; j < (int)str.size(); j++)
            words[i] += (1 << (str[j] - 'a'));
    }
    cout << go(0, k, 0) << '\n';
    return 0;
}
```

## 배운 점
1. **"각 원소를 넣는다 / 안 넣는다"로 분기하는 DFS 백트래킹**이 부분집합 전탐색의 또 다른 표현임을 체득. 비트마스킹 전체 순회(`for i in 0..(1<<n)`)와 같은 공간을 재귀로 훑는 것 — [[project_19942_insight]]의 부분집합 순회와 짝.
2. **무조건 포함되는 원소는 분기에서 빼고 파라미터로 고정**하면 탐색 폭이 줄고 코드가 깔끔해짐 (antic 5글자 처리).
3. `(word & mask) == word` → "word의 비트가 mask에 전부 포함되는가" = 부분집합 판정 idiom.
4. `k < 0` 가지치기로 학습 한도를 넘는 경로를 즉시 차단.

## 깨달음 (사용자 메모)
- DFS 백트래킹 구현을 **더 명확하게** 잡을 수 있어야겠다. 그래야 코드를 더 짧고 간결하게 완성할 수 있겠다는 깨달음을 얻음.
- 다음 백트래킹 문제에서는 can/do/undo 분리([[project_14620_insight]])나 "넣는다/안 넣는다" 분기 구조를 손에 익을 때까지 일관되게 쓰는 게 목표.
