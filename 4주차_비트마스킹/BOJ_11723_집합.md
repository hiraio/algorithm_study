# BOJ 11723 — 집합 (비트마스킹 기본 연산 6종)

**날짜**: 2026-04-14  
**유형**: 비트마스킹 기본

## 잘한 부분
- add/remove/check/toggle/all/empty 여섯 연산의 비트 연산 매핑을 스스로 도출 (`|=`, `& ~`, `&`, `^`, `(1<<21)-1`, `0`)
- `1 << (idx-1)` 대신 `1 << idx`로 통일하는 관례 선택도 스스로 판단

## 막혔던 포인트
- 처음에 add를 배열 인덱싱(`a[2 << n]`)으로 접근 — "집합=정수 하나"가 아닌 "집합=크기 20 배열" 사고에 갇혀있었음
- add 함수에 중복 체크(`if(s & (1<<idx)) return;`)를 넣음 — `|=`가 멱등이라 불필요
- `ios_base::sync_with_stdio(false); cin.tie(NULL);` 누락으로 TLE (M ≤ 3,000,000)

## 배운 점
1. **"집합 = 정수 하나"**: 비트마스킹은 배열 대체가 아니라 사고 단위 전환. 20개 원소의 집합 상태 전체가 `int s` 한 개 안에 들어감
2. **AND vs XOR의 의미 차이**: `&`는 "정보 추출"(읽기), `^`는 "상태 변경"(토글). 의도-연산자 매핑을 익혀야 함
3. **`|=`의 멱등성**: 이미 켜진 비트에 `|=`해도 결과 동일. add에 중복 체크 불필요
4. **C++ 코테 국룰**: `ios_base::sync_with_stdio(false); cin.tie(NULL);` 2줄은 main 시작 템플릿으로 고정. `endl` 대신 `'\n'` 사용
5. **`cin >>` + `getline` 섞을 땐 `cin.ignore()` 필수**

## 느낀 점
