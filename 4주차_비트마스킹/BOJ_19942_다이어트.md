# BOJ 19942 — 다이어트 (비트마스킹 부분집합 순회 + 사전순 tiebreak)

**날짜**: 2026-04-20  
**유형**: 비트마스킹 부분집합 순회

## 잘한 부분
- "조합으로 풀 수 있는데 왜 비트마스킹 주차?"라는 메타 질문을 스스로 던짐 — 비트마스킹을 "같은 부분집합 탐색의 다른 표현"으로 이해한 신호
- `for(i=0; i<(1<<n); i++)` 전체 순회 구조도 막힘 없이 작성
- 0-인덱스 비트 + 1-인덱스 배열 매핑(`idx = j+1`)으로 깔끔하게 정리

## 막혔던 포인트
1. **조건 방향 뒤집힘**: `mp >= sumP` (기준치 ≥ 섭취량)으로 썼는데 "섭취량 ≥ 기준치"여야 함
2. **sum 초기화 함정**: `int sumP, sumF, sumS, sumV, sumC = 0;` — C++에선 마지막 변수에만 0 대입
3. **비트 인덱싱 불일치 (가장 치명적)**: i 루프는 `< (1 << n)`으로 비트 0~n-1, 내부 j 루프는 `1 << j` with `j=1..n`으로 비트 1~n 검사 → n=15일 때 식재료 15번이 영원히 누락
4. **사전순 비교를 마스크 정수끼리 하려고 함**: 반례 존재 — 사전순은 인덱스 리스트 자체끼리 비교해야 함
5. **vector 메서드 오용**: `pop()` → `pop_back()`
6. `cin.tie(null)` → `NULL`/`nullptr`

## 배운 점
1. **비트마스킹 = 부분집합 탐색의 간결한 표현**. `for(i=0; i<(1<<n); i++)` 한 줄로 모든 부분집합 순회 + 상태가 정수 하나. N ≤ 20 정도가 마지노선
2. **vector의 `<` 연산자는 자동 사전순 비교**. 사전순 tiebreak 관용구:
   ```cpp
   if (sumC < minC || (sumC == minC && currN < minN)) { minC = sumC; minN = currN; }
   ```
3. **0-인덱스 비트 + 1-인덱스 배열 매핑 idiom**: `for(j=0; j<n; j++) if(i & (1<<j)) { int idx = j+1; ... }`
4. **여러 변수 초기화는 한 줄로 묶지 말 것**: `int a=0, b=0, c=0;`

## 느낀 점
