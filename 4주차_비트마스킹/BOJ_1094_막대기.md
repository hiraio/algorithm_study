# BOJ 1094 — 막대기 (2진법 변환 = 켜진 비트 세기)

**날짜**: 2026-05-30
**유형**: 비트마스킹 / 진법 변환 통찰 (문제의 본질을 꿰뚫으면 한 줄짜리)

## 핵심 통찰
- 막대를 절반씩 쪼개 64에서 X를 만드는 과정 = **X를 2의 거듭제곱의 합으로 분해**하는 것
- 따라서 남는 막대 개수 = **X를 2진수로 표현했을 때 켜진 비트(1)의 개수**
- 즉 `__builtin_popcount(x)` 또는 비트 세기 한 번으로 끝나는 문제

## 내가 처음 시도한 풀이 (돌아간 풀이)
- 막대를 실제로 쪼개고 또 쪼개서, 남은 막대들을 더해 X와 비교하고, 그때 켜진 비트 수를 세는 식으로 시뮬레이션하려 함
- → 문제의 본질(= 2진 표현의 1 개수)을 못 보고 과정을 그대로 흉내 내려다 복잡해짐

## 깨달음
- **"과정을 그대로 시뮬레이션"하기 전에 "이 과정이 결국 무엇을 계산하는가"를 한 발 물러나 보자.**
- 쪼개기/더하기/비교 루프 전체가 사실 "2진수 자릿수 세기" 하나로 환원됨. 문제를 수학적으로 재해석하면 코드가 극적으로 짧아진다.

## 강의식 코드
```cpp
#include<bits/stdc++.h>
using namespace std;
int n, ret = 1;          // 64짜리 막대 1개에서 시작 → ret 초기값 1
int main(){
    ios_base::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);
    cin >> n;
    while(n != 1){
        if(n & 1) ret++;   // 켜진 비트마다 막대 하나 추가
        n /= 2;
    }
    cout << ret << '\n';
    return 0;
}
```
> `ret`을 1로 시작하고 `n`을 2로 나눠가며 최하위 비트만 검사. n이 1이 되면(최상위 비트) 종료.

## 참고: 특정 숫자 n진법 변환 (교안 idiom)
나머지를 모아 뒤집는 표준 패턴. **16진법까지 커버**하려면 10 이상은 문자(A~F)로 변환.
```cpp
#include<bits/stdc++.h>
using namespace std;
vector<int> v;
int main(){
    int n = 100;
    int b = 2;            // 진법(base)
    while(n > 1){
        v.push_back(n % b);
        n /= b;
    }
    if(n == 1) v.push_back(1);
    reverse(v.begin(), v.end());
    for(int a : v){
        // 16진법: 10~15는 A~F로. 'A' == 65, 10 + 55 == 65
        if(a >= 10) cout << char(a + 55);
        else cout << a;
    }
    return 0;
}
```
- **핵심 idiom**: `나머지 push → 몫으로 갱신 → 끝나면 reverse`. 자릿수가 역순으로 쌓이므로 마지막에 뒤집는다.
- `char(a + 55)`: 10→'A'(65) 매핑. (`'A' - 10 == 55`)
- 1094는 이 변환의 "2진법 + 1의 개수만 세기" 특수 케이스.
