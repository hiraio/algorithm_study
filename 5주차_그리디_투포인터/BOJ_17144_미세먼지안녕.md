# BOJ 17144 — 미세먼지 안녕!

- **날짜**: 2026-07-05 (일)
- **유형**: 시뮬레이션 (격자 동시 확산 + 공기청정기 순환 회전)
- **결과**: AC (확산·순환 디버깅 후)

## 핵심 아이디어

T초 동안 매초 두 단계를 반복 → 남은 먼지 총합 출력.

1. **확산**: 모든 먼지 칸이 **동시에** 상하좌우로 `A/5`씩 퍼짐(공기청정기 `-1` 방향·격자 밖 제외). 퍼진 방향 수만큼 자기 칸에서 빠짐.
2. **공기청정기 순환**: 위쪽은 반시계, 아래쪽은 시계 방향으로 바람이 한 칸씩 밀어냄.

**큰 교훈**: 복잡해 보이는 문제도 **독립된 단계(함수)로 분해**하면 각개격파가 된다. 여기선 딱 `확산()` + `순환()` 두 덩어리.

## 막혔던 포인트 1 — 확산의 "동시성"

- 판 하나로 제자리 갱신하면, 먼저 처리한 칸이 뿌린 먼지가 **아직 처리 안 한 옆 칸의 원본**에 섞여 순서에 따라 결과가 달라짐(= in-place 오염).
- 해결: **`temp` 별도 배열에 누적(+=)** 후 `board`로 복사. `temp`는 매초 0으로 리셋(단 `-1` 자리는 유지).

### 디버깅한 버그들

```cpp
// (1) 퍼지는 양의 기준이 뒤바뀜
temp[ny][nx] += (board[ny][nx] / 5);   // ✗ 옆 칸 값 기준
temp[ny][nx] += (board[i][j]  / 5);    // ✓ "지금 칸"이 확산의 주인
temp[i][j]   -= (board[i][j]  / 5);    // 나가는 양과 기준이 같아야 보존됨

// (2) 공기청정기(-1)가 확산 루프에 끼어듦
if(board[i][j])       // ✗ -1도 truthy → 청정기 칸 오염(-1이 -2로)
if(board[i][j] > 0)   // ✓
```

- 핵심: **나가는 양과 들어가는 양의 기준이 같아야 총량 보존.** 둘 다 `board[i][j]/5`.
- 자기 칸 남는 양은 `=`가 아니라 `+=`로 처리해야 옆에서 들어온 먼지와 안 부딪힘.

## 막혔던 포인트 2 — 공기청정기 순환(당겨오기)의 인덱스

바람 반대 방향으로 값을 한 칸씩 "당겨오는" 방식. 네 좌표 규칙 = **`C`=행 수, `R`=열 수 → 유효 열은 `0 ~ R-1`(마지막 열은 `R`이 아니라 `R-1`)**.

위쪽(반시계) 4구간:

```cpp
for(int i = topY-1; i > 0; i--) board[i][0]   = board[i-1][0];    // 좌: 세로줄
for(int i = 0; i < R-1;  i++)   board[0][i]   = board[0][i+1];    // 위: 가로줄
for(int i = 0; i < topY; i++)   board[i][R-1] = board[i+1][R-1];  // 우: 세로줄 (R-1!)
for(int i = R-1; i > 1;  i--)   board[topY][i]= board[topY][i-1]; // 청정기 행: 가로줄
board[topY][1] = 0;                                               // 청정기 옆은 깨끗한 바람
```

디버깅한 실수:
- **열 범위 초과**: `board[i][R]` → `board[i][R-1]`.
- **행/열 축 뒤집힘**: 청정기 "행"인데 `board[i][topY]`로 세로줄을 건드림 → `board[topY][i]`.
- **무한루프**: `for(int i=2; i<=R;)` 증감식 누락 + 방향(큰 인덱스→작은 인덱스) 실수.

> 규칙 하나로 기억: **세로줄 훑기 = 열 고정·행 변화 / 가로줄 훑기 = 행 고정·열 변화.** 청정기 "행"인데 행(topY)이 변수 자리면 뒤집힌 것.

아래쪽(시계)은 이걸 위아래로 뒤집은 대칭.

## 배운 점

- **동시 갱신 시뮬은 `temp` 별도 배열이 정석.** in-place는 순서 의존 버그를 부른다.
- **보존 법칙 체크**: "나간 양 == 들어간 양"이 안 맞으면 기준(주어)이 어긋난 것.
- 큰 규칙일수록 **독립 함수로 쪼개고 각각을 좌표로 검증**. `-1`(청정기)은 truthy라 `> 0` 가드 필수.
