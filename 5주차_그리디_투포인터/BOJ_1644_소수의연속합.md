# BOJ 1644 — 소수의 연속합

- **날짜**: 2026-06-19 (금)
- **유형**: 에라토스테네스의 체(소수 생성) + 투포인터(연속 부분합)
- **결과**: AC

## 문제 핵심

자연수 N을 **연속된 소수들의 합**으로 나타내는 경우의 수. (N ≤ 400만)
- 예: 41 = 2+3+5+7+11+13 = 11+13+17 = 41 → 3가지

## 골격: 소수 리스트 만들고 → 투포인터로 연속합 세기

1. **에라토스테네스의 체**로 N 이하 소수를 `vector`에 모은다.
2. 소수 리스트 위에서 **투포인터**(lo, hi)로 구간합을 N과 비교:
   - 합 < N → hi 전진(더 더함)
   - 합 > N → lo 전진(앞을 뺌)
   - 합 == N → 카운트 + 한쪽 포인터 전진

## 외워둘 코드 — 에라토스테네스의 체 (내 버전)

```cpp
// is_not_prime[i] == true  →  i는 소수가 아님
vector<bool> is_not_prime(N + 1, false);
is_not_prime[0] = is_not_prime[1] = true;   // 0,1은 소수 아님

for (int i = 2; (long long)i * i <= N; i++) {
    if (is_not_prime[i]) continue;          // 이미 걸러진 합성수면 skip
    for (int j = i * i; j <= N; j += i)     // i*i부터 시작(i*2~는 이미 처리됨)
        is_not_prime[j] = true;
}

vector<int> primes;
for (int i = 2; i <= N; i++)
    if (!is_not_prime[i]) primes.push_back(i);
```

**체 핵심 포인트 (왜 이렇게 쓰는가):**
- 바깥 루프는 `i*i <= N`까지만. (i*i > N이면 그 위 합성수는 이미 더 작은 소인수로 걸러짐)
- 안쪽은 `j = i*i`부터. (i*2, i*3 …은 2,3,… 차례에 이미 지워짐 → 중복 제거로 빨라짐)
- `i*i` 오버플로 주의 → N이 크면 `(long long)i*i` 비교.

## 투포인터 연속합 (소수 리스트 위에서)

```cpp
long long sum = 0;
int lo = 0, hi = 0, cnt = 0;
int M = primes.size();

while (hi <= M) {            // hi가 끝을 넘는 순간까지
    if (sum >= N) {          // 같거나 크면 앞을 뺀다
        if (sum == N) cnt++;
        sum -= primes[lo++];
    } else {                 // 작으면 뒤를 더한다 (hi == M이면 더 못 더하므로 종료 조건과 함께)
        if (hi == M) break;
        sum += primes[hi++];
    }
}
```
> 정렬 불필요: 체에서 이미 오름차순으로 담았다.

## 배운 점 / 다음에 떠올릴 트리거

- **"연속 부분합 = 정렬 안 건드리고 투포인터"** 패턴. 양수 배열에서 구간합이 단조라 lo/hi 한 방향 전진으로 O(M).
- 체는 자주 쓰는 idiom이니 **위 골격을 내 버전으로 통째 암기**하기로 함 (`i*i`부터, `i*i<=N`까지가 두 핵심).
