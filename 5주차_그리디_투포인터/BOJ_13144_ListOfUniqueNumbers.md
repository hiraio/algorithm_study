# BOJ 13144 — List of Unique Numbers

- **날짜**: 2026-06-19 (금)
- **유형**: 투포인터(슬라이딩 윈도우) + visited 배열
- **결과**: AC

## 문제 핵심

길이 N 수열에서 **원소가 전부 서로 다른 연속 부분수열의 개수**. (N ≤ 10만, 값 ≤ N)
- 답이 최대 N(N+1)/2 ≈ 50억 → **long long 필수**

## 왜 O(N²)이 안 되나

이중 for문으로 모든 (시작, 끝) 조합 검사 = O(N²) = 10¹⁰ → TLE.
→ 투포인터로 **left는 뒤로 안 가고 앞으로만** → O(N).

## 막혔던 지점: 중복 만났을 때 포인터를 어디로?

내가 막힌 곳 = "조건(중복 등장)을 만족시킬 때 포인터를 어떻게 이동해야 빠짐없이/중복없이 다 세는가".

**해결한 규칙:**
- `a[right]`가 이미 창에 있으면 → left를 **한 칸씩 빼면서 전진**, 그 중복값이 창에서 사라질 때까지. (left++ 한 번이 아님)
- 창이 유효해진 직후 **`right - left + 1`을 답에 더한다** = "right에서 끝나는 유효 부분수열 개수".
- 모든 right에 대해 더하면 모든 유효 부분수열이 **끝점 기준 정확히 한 번씩** 세어짐 → 빠짐/중복 자동 해결.

## 골격

```cpp
long long ans = 0;
int left = 0;
vector<bool> visited(N + 1, false);

for (int right = 0; right < N; right++) {
    while (visited[a[right]]) {     // 들어올 값이 이미 창에 있으면
        visited[a[left]] = false;   // 왼쪽부터 비우며
        left++;                     // 창을 줄인다
    }
    visited[a[right]] = true;
    ans += (right - left + 1);      // right에서 끝나는 부분수열 수
}
```

## 배운 점 / 다음에 떠올릴 트리거

- **"특정 조건(중복)을 만족할 때 포인터 방향을 어떻게 옮길지 구상하는 게 투포인터의 본체"** 라고 체감. 답 누적 공식(`right-left+1`)을 끝점 기준으로 잡으면 카운팅이 깔끔해진다.
- while로 left를 "조건이 풀릴 때까지" 미는 슬라이딩 윈도우 골격은 다른 문제에도 재사용. while 조건 = `visited[a[right]]`.
